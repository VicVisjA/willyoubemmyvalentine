# 💖 Interactive Valentine Proposal (Front-End Micro Experience)

## Overview

This project is an interactive Valentine’s Day web experience built using HTML, CSS, and Vanilla JavaScript. It presents a playful UI interaction where the user is asked a question and the interface dynamically responds based on their input.

The application demonstrates event-driven UI manipulation, DOM updates, dynamic styling, and interactive state transitions — all without external libraries.

## Key Features

- Responsive centered layout
- Dynamic button resizing and animation
- Progressive text updates on user interaction
- Randomized button movement behavior
- Conditional UI rendering (question → success screen)
- CSS animations and transitions
- DOM manipulation using pure JavaScript
- GIF-based visual feedback

## Technical Highlights

- Pure JavaScript (no frameworks)
- Event-driven architecture
- Real-time style manipulation via JavaScript
- State tracking using counters and arrays
- Interactive UX logic with progressive feedback
- Clean UI structure with CSS animations
- Conditional rendering without page reload

## How to Run

Open the `.html` file in any modern browser.  
No installation or dependencies required.
